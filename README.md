# 🧑‍🎓 Student Forum

A simple and secure student forum web application built with **Angular 19** (Frontend) and **Laravel Sanctum** (Backend API). This platform allows students to register, log in, post topics, and engage in academic discussions.

---

## 📁 Project Structure

student-forum/
├── backend/ # Laravel API with Sanctum
└── frontend/ # Angular 19 SPA

---

## 🛠️ Tech Stack

### Frontend (Angular 19)
- Angular CLI
- Angular Router
- Angular Forms & HTTPClient
- Bootstrap or Tailwind CSS (optional)
- JWT support with Laravel Sanctum

### Backend (Laravel)
- Laravel 11+
- Laravel Sanctum for authentication
- RESTful API structure
- MySQL or SQLite (recommended for development)
